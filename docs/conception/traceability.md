**Gaps this matrix shows.**
- R2 has no visible step: its effect is only on which sources are cited
  (measured in [R2-rag.md](../performance/R2-rag.md)).
- EV2's input filter runs in the CLI and in `sensai-web` (checked in
  `web/runtime.py` on 2026-11-01) and on scheduled tasks (`scheduling/runner.py`). Tool results
  are cleaned and, since 2026-11-01, fenced as untrusted data (former gap
  EV4-OUT-14). The model's answer and its `thought` text are both filtered (ADR-0058).
- The CLI does not record sub-agent tool calls in the journal ([backlog](../backlog.md) #5),
  so S6 is only fully traced in the web.
