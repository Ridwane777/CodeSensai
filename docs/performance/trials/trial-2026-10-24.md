# Full trial of all features - 2026-10-24

State of `main` after PR #87 (A2 and T5), tried end to end with the real
model to check that the features work **together**. Previous trials:
[2026-10-13](trial-2026-10-13.md), [2026-10-14](trial-2026-10-14.md).

## Machine and method

- **Model**: `qwen3-coder:30b` and `bge-m3` on a fresh RunPod pod (24 GB
  GPU), through the RunPod HTTP proxy. The pod address is not in the repo.
- **Client**: Linux machine (Intel i7-1355U, 12 cores, 14 GB RAM),
  Python 3.12, local Docker for the sandboxes.
- **Method**: a script drives the **real CLI** `sensai` (subprocess, "y"
  answers to confirmations) in a throwaway project: `calcul.py` (typo),
  `stats.py` (bug with negatives), `texte.py`, `reglages.py` (fake API key),
  `README.md`, a one-page PDF and a JSON schema. Then the **real web server**
  (`sensai-web`) through its HTTP API. Throwaway data folders; `~/.sensai`
  untouched.
- One measurement per scenario: orders of magnitude.

## Limits

- One measurement per scenario, a single model, a single network.
- The web server is tried through its API, not through the interface in a
  browser; the display of agent handoffs and MCP tools remains simulated
  there.
- The MCP client has not yet been tried with a published MCP server (only the
  repo's test server).
