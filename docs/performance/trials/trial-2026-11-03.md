# Trial 2026-11-03: features limited by ADR-0056, with the real model

Three behaviours introduced or changed by
[ADR-0056](../../decisions/0056-scope-review-features-to-drop-or-limit.md) and
[ADR-0058](../../decisions/0058-filtered-answers-and-context-command.md) were
until now checked only by automated tests (fake model). This trial checks them
with the real model.

**Machine**: a new RunPod pod (24 GB GPU), Ollama serving `qwen3-coder:30b`
(Q4_K_M, 100 % in VRAM, `OLLAMA_CONTEXT_LENGTH` 16384; CodeSensai sends its own
`num_ctx` 8192). The code ran on the team laptop. The pod address is not in
the repository.

**Project**: a throwaway git folder with `stats.py` (`moyenne`, which divides
by zero on an empty list) and `tests/test_stats.py` (one passing test). CLI
`sensai --new-session --no-rag`, fresh `--data-dir`, answers to the
confirmations typed through a pipe.

## Issues found

- **Wrong summary after a correct team run (#2).** The final answer quoted
  a `ValueError` message and an `assertRaises` test that are not what was
  written in the files (the files themselves are right and the tests pass). The
  developer's report is summarised, not re-read. Backlog #23.
- **Unneeded web search (#3).** The explorer called `web_search` twice for a
  task about a local file. Backlog #24.
- **Fake tool tag (#3).** In a later team run, `team_task`'s output was
  flagged `forged_tool_markup` by the gateway: a `<tool_call>` written as text
  was caught, as intended.
- **Not an agent issue:** in #3, the extra team runs came from the trial
  script, which kept typing "o"; the agent read them as "yes" to its own
  question. One request, one approval, is how the trial should have been driven.
- **Near-miss key (#5).** A string that only looks like an AWS key is not
  masked; only the exact format is (`execution/guardrails.py`), so that
  ordinary identifiers are not masked; the generic secret pattern caught the
  other line.

## What this closes

The three behaviours that were only unit-tested (share links off, tests as
the team's verdict, the model's own answer filtered) have now been seen
with the real model, in passing and failing cases for `team_task`.
